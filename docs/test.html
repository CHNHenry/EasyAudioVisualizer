SoundProcessor 参数测试

麦克风 / 系统内录只用于分析，不会回放到扬声器（避免啸叫）。系统内录仅 Chrome / Edge 支持：在弹出的共享窗口中选择“整个屏幕”或“标签页”，并勾选“分享音频”。

基础参数

作用：参与计算每个 FFT 频点的带宽（bandwidth = sampleRate ÷ fftSize），并把频率换算成频点索引来做倍频程分带，它不会改变真实采集到的数据。效果：留空自动取 AudioContext 的真实采样率（通常 48000），推荐保持默认。手动调大 → 每个频点被视为覆盖更宽的频率，同一频带分到的频点变少，输出整体偏低；调小则相反，输出偏高且频带错位。
作用：FFT 窗口大小，决定频率分辨率（sampleRate ÷ fftSize ≈ 每个频点多少 Hz）与频点总数（fftSize ÷ 2），会同步设置 AnalyserNode。效果：越大，低频分得越细（4096 时约 11.7Hz/点），但每帧覆盖的时间窗更长，画面响应更迟缓；越小则响应快，但低频糊成一团。
作用：倍频程划分的起始频率，只取该频率以上的信号。效果：调高（如 1000+）可滤掉低频轰鸣与底噪，突出人声和旋律；调低则贝斯、底鼓更抢眼。注意不能填 0：库内用 log2(end ÷ start) 求倍率，填 0 会让输出全部变成 NaN（信息面板会给出警告）。
作用：倍频程划分的截止频率上限。效果：调低可聚焦人声与鼓点等中低频，画面更有节奏感；调高会纳入镲片、气声等高频细节，但高频能量本身较弱（A计权后更弱），柱子通常很矮。README 建议一般音乐取 50~10000Hz 区间。
作用：输出频带数，即可视化目标数量（柱子数/圆点数）。程序按倍频程把 [start, end] 划成 N 个带，每个带的上限是下限的 2^(1/N) 倍。效果：越大 → 带宽窄、细节多，但单带能量弱、画面偏矮偏碎；越小 → 每带越宽、更有力度，适合少量大元素的风格。填得过大导致某些带超出 endFrequency 时，对应输出会是 0 或 NaN。

开关

作用：时间计权，对最近 5 帧频谱取平均，抑制帧间突变（WebAudio 自带的 smoothingTimeConstant 只平均 2 帧且无法关闭）。效果：开启后波形随时间更平滑、有拖尾与呼吸感，鼓点瞬态被柔化，适合缓慢律动的视觉风格；关闭则逐帧忠实还原，跳动更硬朗、更带感。
作用：A 计权（声学标准曲线），给每个频点乘一个系数，模拟人耳对 1~5kHz 最敏感、对低频与超高频不敏感的听觉特性。效果：开启后低频被压低、中频（人声区）突出，画面能量分布接近“听起来的响度”；关闭则是纯物理能量，低音很猛，但中频细节容易被低频淹没。
作用：是否启用高斯滤波。WebAudio 已内置 blackman 窗做一次平滑，这里再补一层卷积滤波，目的纯粹是服务视觉效果。效果：开启后相邻频点的突刺被抹平，柱状图更圆润流畅；关闭则保留原始毛刺，画面更锐利，但可能有单根柱子突跳。
作用：忽略上方 fftSize，改用 8192/2048/512 三条支路并行 FFT。每条倍频程频带自动挑选「带宽 ≥ 频点宽」中响应最快的支路——低频走 8192 求清晰、高频走 512 求迅速，近似恒Q变换（CQT）。开启后 fftSize 与高斯滤波不参与，时间计权/A计权仍生效（按频带粒度）。效果：低频各带彼此分开，贝斯与鼓点层次分明；高频保持约 21ms 的快速响应。代价：低频支路窗长约 170ms，低频响应天然偏钝；支路交叉处按 3dB/倍频程 做接缝校准（近似值）。运行时信息面板会显示每条支路分到的频带数与交叉点频率。

滤波参数 filterParams

作用：高斯分布的 σ 参数，决定卷积核的形状，README 建议 0.1~250。效果：越大平滑越强——毛刺消失、峰变矮变宽；过大会把整条频谱抹成一条平缓曲线，细节尽失；0.1 左右几乎等于不滤波。
作用：滤波半径，卷积核实际长度为 2×radius+1；radius 为 0 时相当于不滤波。效果：越大，参与平均的邻点越多、平滑范围越宽，峰值的延迟感与细节损失也越明显。
